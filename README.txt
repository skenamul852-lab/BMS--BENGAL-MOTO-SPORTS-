BMS — Bengal Moto Sports website starter

1. Open index.html in a browser to preview.
2. To publish free: create a GitHub repository, upload index.html, then enable Settings → Pages → Deploy from branch.
3. The membership form currently prepares a WhatsApp message; it does NOT save applications to a database and does NOT provide Mobile OTP login.
4. To make OTP login and private admin/member records real, connect an authentication + database backend (for example Firebase) and configure it before collecting member data.
5. Replace the sample photos and add your official BMS logo / WhatsApp admin number before publishing.
